---
description: Build and Push to Master
---

GitHubの`master`ブランチへプッシュする際、Netlifyでのデプロイ失敗を防ぐための必須手順です。

1. 作業内容が完了し、`task.md`および`walkthrough.md`が更新されていることを確認する。
2. 以下のコマンドを実行し、ビルドエラーがないか確認する。
// turbo
```bash
npm run build
```
3. ビルドが成功した（`Exit code: 0`）場合のみ、次のステップへ進む。失敗した場合は修正を行い、ステップ2を再試行する。
4. ユーザーに変更内容を報告し、コミット・プッシュの最終確認を行う。
5. ユーザーの承諾を得た後、変更をコミットし、プッシュする。
